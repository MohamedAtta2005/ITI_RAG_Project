STAGE 01 / 06

Document Parsing & Chunking

Every Stranger Things novel is a PDF. We flatten it to Markdown, then split it back into clean, per‑page chunks tagged with their source book.

Extract text with PyMuPDF

Each page becomes a labeled Markdown block, preserving page order for later citation.

parse.py
import pymupdf


def pdf_to_markdown(pdf_path, markdown_path):
    """Extract the text from a PDF and save it as a Markdown file."""

    markdown = []

    with pymupdf.open(pdf_path) as pdf:
        for page_number, page in enumerate(pdf, start=1):
            markdown.append(f"## Page {page_number}\n\n")
            markdown.append(page.get_text())
            markdown.append("\n\n")

    with open(markdown_path, "w", encoding="utf-8") as file:
        file.write("".join(markdown))

    print(f"Markdown file created: {markdown_path}")


pdf_to_markdown("Assets/strangerthings.pdf", "output.md")

Clean and chunk by book range

Whitespace is normalized, then each page number is mapped to its Stranger Things novel before being written to its own chunk file.

def get_book_name(page_number):
    for book_name, first_page, last_page in BOOK_RANGES:
        if first_page <= page_number <= last_page:
            return book_name
    return None

STAGE 02 / 06

Embeddings & Vector Storage

Each Hawkins page becomes a normalized dense vector, then lands in Qdrant with its book name and page number as payload.

multilingual‑e5‑large

Passages are prefixed with passage: per the e5 convention, then encoded and L2‑normalized for cosine search.

embed.py
from sentence_transformers import SentenceTransformer

MODEL_NAME = "intfloat/multilingual-e5-large"

texts = [f"passage: {page['content']}" for page in pages]

model = SentenceTransformer(MODEL_NAME)
embeddings = model.encode(
    texts,
    normalize_embeddings=True,
    show_progress_bar=True,
).tolist()

Qdrant collection, Cosine distance

Book name, page number, and full content ride along as payload metadata on every point.

store.py
from qdrant_client import QdrantClient, models

client = QdrantClient(url=QDRANT_URL, api_key=QDRANT_API_KEY)

if not client.collection_exists(QDRANT_COLLECTION):
    client.create_collection(
        collection_name=QDRANT_COLLECTION,
        vectors_config=models.VectorParams(
            size=len(embeddings[0]),
            distance=models.Distance.COSINE,
        ),
    )

points = [
    models.PointStruct(id=i, vector=vec, payload=page)
    for i, (page, vec) in enumerate(zip(pages, embeddings))
]

client.upsert(collection_name=QDRANT_COLLECTION, points=points)
print(f"Uploaded {len(points)} pages of Hawkins lore to Qdrant.")
STAGE 03 / 06

Query Intent Routing

Before touching the vector store, a small Groq model decides what kind of message just came in from Hawkins.

Three routes

  • retrieve — needs facts from the novels (Eleven, Vecna, Hawkins Lab, the Mind Flayer)
  • chitchat — greetings or small talk, answered directly
  • off-topic — unrelated to Stranger Things, politely declined

Example

"Who is Number One at Hawkins Lab?" → retrieve

"Hey, how's it going?" → chitchat

router.py
from langchain_groq import ChatGroq
from langchain_core.messages import SystemMessage, HumanMessage

router_llm = ChatGroq(
    model=os.getenv("GROQ_MODEL"),
    api_key=os.getenv("GROQ_API_KEY"),
    temperature=0,
)

SYSTEM_PROMPT = """You classify messages for a Stranger Things book search system.
Return exactly one label and nothing else:
retrieve - questions about Hawkins, Eleven, Vecna, the Mind Flayer, Hopper, or events in the books
chitchat - greetings, thanks, or casual conversation, which you can answer directly
off-topic - anything unrelated to the books, and tell the user you only answer questions about the Stranger Things novels"""

router_messages = [
    SystemMessage(content=SYSTEM_PROMPT),
    HumanMessage(content=query),
]

route = router_llm.invoke(router_messages).content.strip().lower()
route = route.splitlines()[0].strip(" `.,:")

if route not in {"retrieve", "chitchat", "off-topic"}:
    route = "off-topic"
STAGE 04 / 06

The Retrieval Engine

Two complementary passes over the archive: meaning‑based semantic search, and exact‑term keyword search.

Semantic search

The query is embedded with the same e5 model, then Qdrant returns the closest Hawkins pages by cosine similarity.

semantic_search.py
query_vector = model.encode(
    [f"query: {query}"],
    normalize_embeddings=True,
)[0].tolist()

results = client.query_points(
    collection_name=QDRANT_COLLECTION,
    query=query_vector,
    limit=top_k,
).points

context = ""
for result in results:
    page = result.payload
    context += (
        f"Book: {page['book_name']}\n"
        f"Page: {page['page_number']}\n"
        f"Content: {page['content']}\n\n"
    )

Keyword search

A simple term‑frequency pass across all loaded pages — useful for exact names like "Eleven Vecna" where wording matters.

keyword_search.py
keyword_query = "Eleven Vecna"
keywords = keyword_query.lower().split()
keyword_results = []

for page in pages:
    content = page["content"].lower()
    score = sum(content.count(k) for k in keywords)

    if score > 0:
        keyword_results.append({
            "score": score,
            "book_name": page["book_name"],
            "page_number": page["page_number"],
            "content": page["content"],
        })

keyword_results.sort(key=lambda r: r["score"], reverse=True)
STAGE 05 / 06

Grounded Answer Generation

Gemini answers using only what was retrieved — no freelancing about the Upside Down beyond what's on the page.

Strict grounding rule

The system prompt forces an "I don't know" instead of a guess when the retrieved pages don't cover the question.

Example

Q: "Where does Eleven first open a gate to the Upside Down?"

A: Answered only from the three retrieved Hawkins Lab pages, with page citations.

generate.py
from langchain_google_genai import ChatGoogleGenerativeAI
from langchain_core.messages import SystemMessage, HumanMessage

gemini_llm = ChatGoogleGenerativeAI(
    model=os.getenv("GEMINI_MODEL"),
    api_key=os.getenv("GEMINI_API_KEY"),
    temperature=0,
)

messages = [
    SystemMessage(
        content="Answer only from the provided Stranger Things pages. "
                "If the answer is not there, say you do not know. "
                "Keep the answer concise."
    ),
    HumanMessage(
        content=f"Context:\n{context}\nQuestion:\n{query}"
    ),
]

response = gemini_llm.invoke(messages)
print("\nAnswer:")
print(response.text)
